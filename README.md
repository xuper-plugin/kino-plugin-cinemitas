# Cinemitas (Kino plugin)

Películas y series de **cinemitas.org** para [Kino](https://github.com/kinotvapp/kino-light).

Construido sobre la plantilla **channel-kit** (misma base que VerPelis). Resuelve los
servidores de video con el plugin **[Kino Resolver](https://github.com/xuper-plugin/kino-plugin-kino-resolver)**
(se instala solo la primera vez).

- Catálogo de películas y series por géneros, con tabs y buscador.
- Reproducción vía el resolver (inline + navegador para hosters con gate JS).
